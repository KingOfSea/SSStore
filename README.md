# rename.js 节点重命名脚本

用于 **Sub-Store「脚本操作」** 的节点重命名脚本：把各机场五花八门的节点名，统一改写成 `国旗 地区名 序号` 的格式，并可在末尾追加「来源机场」标签（如 `🇺🇸 美国 (Amy)`）。

> 基于 Keywos `rename.js` 改造，新增了「机场标记」功能（`am / amap / ammap / amjson`）以及「参数留空容错」。

- 输入：订阅里的原始节点名（如 `🇹🇼台湾-IEPL`、`郁垒「香港|A」「专线」`）
- 输出：规整后的节点名（如 `🇨🇳 台湾 (八戒) 01`）

## 快速开始

在 Sub-Store 的订阅 / 组合订阅里添加一个「脚本操作」，指向本脚本，参数接在 URL 的 `#` 后面：

```
.../rename.js#flag&one
```

输出示例：

```
🇭🇰 香港 01
🇺🇸 美国 01
🇯🇵 日本        ← 该地区只有 1 个节点, one 去掉了序号
```

本仓库三机场（Amy / 八戒 / 蚯蚓）合并场景的完整参数：

```
flag&one&am=Amy&ammap=八戒>IEPL|Gemini;蚯蚓>「;TAG>丨
```

## 参数怎么传

参数有两种写法，效果一致：

### A. 字符串形式（推荐）

URL 后面 `#`，多个参数用 `&` 连接。开关型参数**不用写值**：

```
#flag&one&clear&am=Amy
```

### B. key-value 形式

在 Sub-Store 的参数输入框里逐条填 key / value。

> ⚠️ **本脚本对留空做了容错**（这是和原版的重要区别）：
> - **开关型**参数：写了 key 即视为**开启**，value 留空也行；只有 value 填 `false / 0 / off / no` 才算关闭。
> - **取值型**参数：value 留空 = **用默认值**。

| key | value | 含义 |
|---|---|---|
| `flag` | （留空） | 开启加国旗 |
| `one` | （留空） | 开启单节点去序号 |
| `am` | `Amy` | 机场标签默认值 |

## 参数详解

### 1. 识别 / 输出

#### `in=` 强制输入识别类型
脚本默认自动判断节点名是中文 / 国旗 / 英文，识别不准时用它强制指定。

| 值 | 含义 |
|---|---|
| `zh` / `cn` | 按中文识别 |
| `en` / `us` | 按英文缩写识别 |
| `flag` / `gq` | 按国旗识别（注意：用 `in=flag` 时，脚本操作前不要再加「国旗」操作，否则国旗被移除后识别不到） |
| `quan` | 按英文全称识别 |

不填时优先级：中文 → 国旗 → 英文全称 → 英文缩写。

#### `out=` 输出地区名形式
| 值 | 输出 | 例 |
|---|---|---|
| `cn` / `zh` | 中文（默认） | `美国` |
| `us` / `en` | 英文缩写 | `US` |
| `gq` / `flag` | 国旗（地区名本身变国旗） | `🇺🇸` |
| `quan` | 英文全称 | `United States` |

#### `nm` 保留未匹配节点
默认会**丢弃**识别不出地区的节点；加 `nm` 则保留它们（原名 + 前缀）。

---

### 2. 国旗 / 前缀

#### `flag` 加国旗
**默认不加国旗**，必须显式带 `flag`。国旗加在地区名前面，例 `🇺🇸 美国`。
> 脚本是按识别到的地区重新拼名字的，原始名里自带的国旗会被丢弃；不传 `flag` 就没国旗。

#### `name=` 机场名前缀
给每个节点加一个固定前缀，例 `name=Amy` → `Amy 🇺🇸 美国`。

#### `nf` 前缀置顶
配合 `name=`，把前缀放到**最前面**（国旗之前）。

---

### 3. 分隔符

#### `fgf=` 各部分分隔符
国旗、地区名、标识等各段之间的分隔符，**默认空格**。例 `fgf=-` → `🇺🇸-美国`。

#### `sn=` 序号分隔符
地区名与序号之间的分隔符，**默认空格**。例 `sn=0` → `美国001`。

---

### 4. 序号

同地区节点会自动编号 `01 02 03 …`。

#### `one` 单节点去序号
某地区只有 1 个节点时，去掉它的 `01`（多个节点的地区不受影响）。

---

### 5. 倍率 / 关键词保留

#### `bl` 保留倍率
正则识别 `0.1x`、`6x`、`3倍` 等，规整成 `×` 后缀保留下来（1 倍率不显示）。

#### `blgd` 保留固定标识
保留 `IPLC`、`IEPL`、`家宽`、`游戏`、`GPT`、`ˣ²` 等固定标识（完整列表见脚本 `valueArray`）。

#### `blkey=` 保留 / 替换自定义关键词
- 用 `+` 连接多个关键词：`blkey=IPLC+NF`
- 用 `>` 做替换：`blkey=GPT>AI` 把 `GPT` 显示成 `AI`
- **区分大小写**

#### `blpx` 分组排序
对带保留标识的节点分组排序，**需配合 `bl` 或 `blgd`**，单独用无效。

---

### 6. 过滤（删节点）

#### `clear` 清理乱名
删掉名字含 `套餐 / 到期 / 剩余 / 官网 / 客服 / 流量 / 订阅 / 测试 …` 的垃圾节点。

#### `nx` 只留低倍率
删掉高倍率节点，只保留 1 倍率与不显示倍率的。

#### `blnx` 只留高倍率
与 `nx` 相反，只保留高倍率节点。

#### `key` 小众过滤
只保留 港 / 新 / 日 / 美 / 韩 / 土 等地区中倍率含 2/4/6/7 的节点，并剔除高序号节点。

---

### 7. 其他

#### `blockquic=` QUIC 开关
- `blockquic=on`  阻止 QUIC
- `blockquic=off` 不阻止
- 不填：删除该字段（默认行为）

#### `debug` 调试
输出处理日志。

---

### 8. 机场标记（重点）

在地区名后面追加「来源机场」标签，例如 `🇺🇸 美国 (Amy)`，方便合并多家机场后区分来源。

#### `am=` 手动指定（最省事）
直接指定机场名，适合**按订阅单独处理**（节点名没有可识别特征时唯一可靠的办法）：

```
#flag&am=Amy        →   🇺🇸 美国 (Amy)
```

#### `amap` 自动判断
开启后，按节点**原始名**里的特征字正则匹配机场（配置见脚本里的 `airportMap`，或用下面的 `ammap=` / `amjson=` 注入）。

#### `ammap=` 紧凑注入（推荐用于合并）
格式：`机场名>正则`，多个用 `;` 隔开：

```
ammap=Amy>Amy|艾米;八戒>Gemini|bajie
```

> 正则里如果要用到 `;` 或 `>` 字面量，请改用 `amjson=`。

#### `amjson=` JSON 注入
适合复杂正则：

```
amjson={"Amy":"Amy|艾米","八戒":"Gemini|bajie"}
```

#### 机场标记规则说明

- **优先级**：`amap/ammap/amjson` 正则命中 > `am=` 手动指定。两者都没命中则不加标记。
- 传了 `ammap=` 或 `amjson=` 会**自动开启**自动判断，不必再加 `amap`。
- 正则**默认忽略大小写**；**自上而下匹配，命中第一个即停**。
- `ammap` / `amjson` 一旦传入，会作为**完整配置**替换脚本内置默认（需列全所有机场）。
- 配置里 key 以 `_` 或 `//` 开头的视为注释，会被忽略。

#### 典型用法

**按订阅单独跑**（每条订阅一个 `am=`，最可靠）：

```
Amy 订阅:  flag&one&am=Amy
八戒订阅:  flag&one&am=八戒
```

**合并成一个组合订阅**（一家无特征的当默认兜底，其余正则命中）：

```
flag&one&am=Amy&ammap=八戒>IEPL|Gemini;蚯蚓>「
```

| 原始节点名 | 输出 |
|---|---|
| `🇭🇰 香港 01`（Amy，干净名→兜底） | `🇭🇰 香港 (Amy) 01` |
| `🇹🇼台湾-IEPL`（八戒，含 IEPL） | `🇨🇳 台湾 (八戒)` |
| `郁垒「香港\|A」「专线」`（蚯蚓，含「） | `🇭🇰 香港 (蚯蚓)` |

> ⚠️ 只能有**一家无特征的机场**当 `am=` 兜底。若有两家节点名都很干净，无法靠正则区分，只能改用「按订阅单独跑」。

---

## 输出名拼接顺序

最终名字按以下顺序拼接（用 `fgf=` 的分隔符连接，空段自动跳过），序号最后由内部加上：

```
[name(nf时)] [国旗] [name(默认)] [地区名] [blkey保留] [bl倍率] [blgd标识] [机场标签] + [sn分隔符][序号]
```

例：`flag&name=机场&blgd&am=Amy` 且节点是美国 IPLC →
`机场 🇺🇸 美国 IPLC (Amy) 01`

---

## 常见组合示例

```
#flag                         🇺🇸 美国 01
#flag&out=us                  🇺🇸 US 01
#out=gq                       🇺🇸 01            (纯国旗, 无中文名)
#flag&clear                   去垃圾节点 + 🇺🇸 美国 01
#flag&one                     单节点地区不带序号
#flag&name=Amy&nf             Amy 🇺🇸 美国 01
#flag&bl&blpx                 保留倍率并分组排序
#flag&nx&clear                只留低倍率 + 去垃圾
#flag&one&am=Amy              🇺🇸 美国 (Amy)    (按订阅单独跑)
```

## 与本仓库配合

`common.conf` 里有「机场分组」直接复用本脚本打的标签来筛选：

```
✈️ Amy = select, include-other-group=♻️ 自动选择, policy-regex-filter=\(Amy\)
🐷 八戒 = select, include-other-group=♻️ 自动选择, policy-regex-filter=\(八戒\)
🪱 蚯蚓 = select, include-other-group=♻️ 自动选择, policy-regex-filter=\(蚯蚓\)
```

所以组合订阅里挂的本脚本参数，必须能正确打出 `(Amy)/(八戒)/(蚯蚓)`，否则机场分组会是空的。

## 注意事项 / 坑

1. **不传 `flag` 就没国旗**——脚本按地区重拼名字，原名国旗会被丢弃。
2. **台湾国旗被强制成 🇨🇳**（脚本逻辑如此）。所以做地区分组筛选台湾时要匹配 `台湾|🇨🇳|🇹🇼`。
3. **key-value 留空**：开关型留空=开启，取值型留空=默认（脚本已容错）。`fgf` / `sn` 留空现在等于默认空格，无法再用「留空」表示无分隔符。
4. **`ammap` 里别用 `;` 和 `>` 字面量**，需要就改 `amjson=`。
5. **机场自动判断依赖节点名特征**。节点名干净（如 `🇭🇰 香港 01`）的机场认不出来，只能靠 `am=` 兜底或按订阅单独跑。
6. **沙箱环境读不了本地文件**：机场配置只能通过参数（`ammap=` / `amjson=`）或脚本内置 `airportMap` 提供。
